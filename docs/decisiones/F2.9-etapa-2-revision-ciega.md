# F2.9 · Etapa 2: revisión ciega

1. Cuando el export real esté listo y la UI A–D esté publicada, abre https://salvamalfa.github.io/aeromexico-tracker/review.html.
2. En «Archivo JSON de respuestas o paquete completo», carga el archivo privado `stage2-review.json`.
3. Revisa las 15 preguntas; cada una muestra aliases A–D aleatorizados y los faltantes aparecen explícitamente.
4. Califica cada respuesta disponible como correcta, problemática o no evaluable.
5. Si quieres, agrega una nota breve sobre la respuesta preferida o la razón de la calificación.
6. La meta estructural es 15 × 4 = 60 espacios; el total de respuestas disponibles queda pendiente del export real.
7. La UI guarda calificaciones en el navegador; usa «Exportar todas las calificaciones» para conservar una copia JSON local.
8. No compartas ni subas el archivo de respuestas, la clave privada de aliases o la copia con calificaciones.
9. El costo real de la etapa queda pendiente de los reportes de ejecución; no hay llamadas ni exportaciones reales todavía.
