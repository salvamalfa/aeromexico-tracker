# F2.9 · Etapa 2: revisión ciega

1. Cuando esté publicada la UI A–D, abre https://salvamalfa.github.io/aeromexico-tracker/review.html.
2. En «Archivo JSON de respuestas o paquete completo», carga el archivo privado `stage2-review.json`.
3. Revisa las 15 preguntas; cada una muestra aliases A–D aleatorizados y los faltantes aparecen explícitamente.
4. Califica cada respuesta disponible como correcta, problemática o no evaluable.
5. Si quieres, añade una nota breve sobre tu respuesta preferida o la razón de una calificación.
6. Son 60 espacios posibles; la disponibilidad real se mostrará al entregar el JSON.
7. La UI guarda calificaciones en el navegador; usa «Exportar todas las calificaciones» para conservar una copia local.
8. No compartas ni subas respuestas, clave de aliases o calificaciones.
9. Coste y respuestas disponibles: se informarán al entregar el JSON.
