# Etapa 15 · Motor cuantitativo

Autorizada por «Continua» después de la explicación y entrega de Etapa 14.
Alcance: un motor determinista sobre un paquete temporal congelado; piloto 2T26.

1. Convertir ASM/TRASM/CASM a ASK/RASK/CASK manteniendo el linaje.
2. Comparar contra trimestres calendario exactos; separar cambios absolutos,
   porcentajes y puntos porcentuales. No usar bases cero o negativas para crecimiento.
3. Calcular spread, combustible/ASK, resto del costo, consumo y costo efectivo.
4. Reconstruir puentes de spread, ingresos y gasto de combustible sin inferir causalidad.
5. Conciliar márgenes y cifras financieras con intervalos de redondeo conservadores.
6. Exponer diferencias y restricciones, guardar resultados versionados y un HTML local.
7. Ejecutar pruebas y detenerse para revisión antes de Etapa 16.

La distinción entre CASK publicado y gasto operativo/ASK se conserva explícita;
un contraste que no reconcilia no se convierte en una identidad financiera válida.

Aceptada posteriormente mediante «Adelante», conservando las cinco diferencias
documentadas. Autoriza Etapa 16, no la aprobación o publicación de un análisis.
